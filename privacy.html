Privacy & credits

OpenCharts is a static, open source chart tool. This page describes what the application itself does with data. When published through GitHub Pages, GitHub says it logs visitor IP addresses for security; see GitHub Pages hosting information and the GitHub privacy statement.

Your charts and data

Files you open and tables you paste are read in your browser. Saved charts are stored in this browser’s local storage, without an account. A table you open in the chart editor can also remain in local storage for up to six hours so you can try another chart. You can clear it in the studio; removing a saved chart deletes that copy from this browser. Export a backup before clearing browser data.

Share links and embeds contain the chart data and settings in the URL. Anyone with that link can read the data inside it. Do not share sensitive tables through a link.

Optional network actions

  • If you enter a data URL, your browser requests that address. The destination may receive normal connection details.
  • Geo charts fetch world boundary data from jsDelivr when opened.
  • If you connect an MCP agent and send a question, OpenCharts sends your message, recent chat, and table through the local bridge to that agent. Your agent provider’s own terms and privacy policy then apply. The connection link is kept in this tab’s session storage.
  • The site does not include advertising or analytics scripts. Your hosting provider may maintain ordinary server logs under its own policy.

Libraries and licenses

OpenCharts source code is available under the MIT license. Chart.js, D3, Apache ECharts, Arquero, chart plugins, map data, and other dependencies have their own licenses. Versions, attribution, and bundled license texts are listed in the third-party notices. Keep the applicable notices with redistributed copies.
