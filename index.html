Pick a chart. Change it. Take the code.

Every chart here opens in a studio where the data, the colours and the options are live controls. What you see is generated from the same definition that produces the code below it — so the snippet you copy is the chart you built, not an approximation of it.

Four ways out. The studio emits the markup, the stylesheet and the script separately, plus a standalone page that inlines all three and runs the moment you open it.

Charts run on Chart.js, D3, plain Canvas 2D or the dependency-free OpenCharts engine — the badge on each tile tells you which before you commit to it.
